# FailSafe E-Commerce - Project Scope

## Purpose
Production-like SRE/DevOps learning platform using a simplified e-commerce workload.

## In Scope
- Microservices
- CI/CD
- Azure infrastructure as code
- Kubernetes
- Observability
- Security baseline
- Load testing and incident simulation

## Out of Scope
- Real payments
- Complex frontend
- Real customer data
